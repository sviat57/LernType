# LernType

**LernType** — локальный настольный тренажёр немецкого языка для Windows 10/11. Он строит маршрут от **A0 до C2**, тренирует перевод между русским и немецким, хранит прогресс в SQLite и автоматически выбирает раскладку `ru-RU` или `de-DE` под ожидаемый ответ.

> Приложение не связано с Goethe-Institut, telc, TestDaF-Institut или BAMF. Встроенный экзаменационный центр содержит справочные схемы форматов и ссылки на первичные официальные источники, а не копии защищённых экзаменационных заданий.

## Возможности

- **Путь A0–C2:** 7 уровней × 7 навыков, явные цели, блокировка следующей ступени до освоения текущей и локальная история попыток.
- **Три ступени практики:** слова, предложения и тексты; отдельно выбираются CEFR-уровень и направление RU→DE / DE→RU / смешанное.
- **Встроенный каталог:** 150 слов, 70 двуязычных предложений (по 10 на A0–C2), 7 текстов (по одному на уровень) и 8 грамматических заданий.
- **Двусторонний словарный тест:** до 20 уникальных вопросов, точность по каждому направлению и разбор ошибок.
- **Моя книга:** вставка русского или немецкого текста до 500 000 символов, пакетное извлечение частотной лексики и тренировка выбранных слов.
- **Офлайн-словарь:** FreeDict/WikDict `rus-deu` и `deu-rus` версии 2025.11.23 в отдельной индексированной SQLite-базе.
- **Экзаменационный центр:** 14 маршрутов Goethe, telc, digital TestDaF и DTZ, секции, длительность, правила оценки, официальные ссылки и индикатор готовности по собственной истории занятий.
- **Грамматика:** локальные эвристики для базового предложения, отрицания, Perfekt, Passiv, Konjunktiv II, косвенной речи, номинализации и причастных определений.
- **Опциональный AI-разбор:** OpenAI Responses API для углублённой обратной связи. Все основные режимы работают без ключа и без сети.
- **Интерфейс:** светлая/тёмная glass-тема, Mica в Windows 11, fallback для Windows 10, экран прогресса и панель `ä ö ü ß`.

## Скачать и запустить

В GitHub Releases выбирайте архив `LernType-<version>-win-x64.zip`. Это автономная сборка: установка .NET не требуется.

1. Распакуйте архив в обычную папку пользователя.
2. Запустите `LernType.exe`.
3. Если Windows запросит подтверждение для приложения без коммерческой цифровой подписи, проверьте SHA-256 из описания релиза и подтвердите запуск.

Для автоматического переключения ввода в Windows должны быть добавлены русская (`ru-RU`) и немецкая (`de-DE`) раскладки.

## Сборка из исходников

Требуются Windows 10/11 x64 и .NET 8 SDK:

```powershell
dotnet restore LernType.sln
dotnet build LernType.sln -c Release -warnaserror
dotnet test LernType.sln -c Release --no-build
dotnet run --project src/WortBruecke.App/WortBruecke.App.csproj
```

Автономная публикация для Windows x64:

```powershell
dotnet publish src/WortBruecke.App/WortBruecke.App.csproj `
  -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=false
```

Исполняемый файл называется `LernType.exe`; внутренние имена проектов `WortBruecke.*` сохранены для совместимости исходного кода и локальных данных ранних версий.

## Первый запуск

1. Добавьте русскую и немецкую раскладки в **Параметры Windows → Время и язык → Язык и регион**.
2. Откройте **Путь A0–C2** и начните с доступного уровня либо используйте словарный тест.
3. В **Тренажёре** выберите ступень материала, CEFR и направление.
4. В **Экзаменах** выберите целевой формат и сверяйте требования по встроенным официальным ссылкам.
5. При желании добавьте API-ключ в **Настройках**. Ключ защищается Windows DPAPI для текущей учётной записи.

Текст отправляется во внешний API только после явного запуска онлайн-разбора. Тренажёр, тест, встроенные тексты, экзаменационные схемы, офлайн-грамматика и содержимое **Моей книги** обрабатываются локально.

## Локальные данные и миграция

Данные находятся в `%LOCALAPPDATA%\LernType`:

- `lerntype.db` — контент, прогресс, история учебных попыток и пользовательские книги;
- `settings.json` — настройки и DPAPI-зашифрованный API-ключ.

При первом запуске LernType переносит прежние данные из `%LOCALAPPDATA%\WortBruecke` и переименовывает `wortbruecke.db`, если новый профиль ещё не создан. Пользовательские книги хранятся отдельно от встроенного каталога и переживают импорт новой ревизии контента.

## Контент и словарь

Каталог находится в `src/WortBruecke.App/Content/catalog.json`, экзаменационные схемы — в `src/WortBruecke.App/Content/exams.json`, изображения — в `src/WortBruecke.App/Assets/Images`.

Словарь расположен в `src/WortBruecke.App/Assets/Dictionary/FreeDict`. Рядом лежат `NOTICE.txt`, текст CC BY-SA 3.0 и `source-manifest.json` с версиями, исходными URL и SHA-512. Конвертер TEI P5:

```powershell
dotnet run --project tools/WortBruecke.DictionaryBuilder -- `
  output.sqlite rus-deu.tei deu-rus.tei
```

Перегенерация встроенного учебного каталога:

```powershell
$text = [IO.File]::ReadAllText(
  (Resolve-Path tools/Generate-MvpContent.ps1),
  [Text.Encoding]::UTF8)
& ([ScriptBlock]::Create($text)) -ProjectRoot (Resolve-Path .)
```

При ручном изменении `catalog.json` увеличьте `revision`, чтобы приложение импортировало новую версию.

## Архитектура

- `WortBruecke.Core` — модели обучения и экзаменов, curriculum A0–C2, оценивание, словарные сессии и грамматические эвристики.
- `WortBruecke.Infrastructure` — SQLite, импорт JSON, офлайн-словарь, DPAPI, OpenAI-клиент и Windows keyboard API.
- `WortBruecke.App` — WPF/MVVM-интерфейс, навигация, темы и учебные сценарии.
- `WortBruecke.Tests` — модульные, интеграционные, persistence-, resilience- и content-тесты.

## Границы текущего релиза

- Покрытие встроенными словами пока плотное для A0–A2 и начальное для B1; уровни B2–C2 опираются главным образом на предложения, тексты и грамматику.
- Навыки аудирования, произношения, письма с развёрнутой оценкой и полный таймерный mock-exam требуют следующих пакетов упражнений. Экран готовности показывает фактическое покрытие и не выдаёт его за официальный результат.
- Книжный режим использует точные словоформы без полноценной морфологической лемматизации; неизвестные формы остаются отмеченными.
- Локальные грамматические эвристики дают учебные подсказки, а не сертификационную оценку.
- Экзаменационные регламенты меняются; в `exams.json` сохранены дата проверки и первичные ссылки для регулярной перепроверки.
