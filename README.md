# LernType

**LernType** — автономный курс немецкого языка для Windows 10/11 и русскоязычных пользователей. Полностью опубликованный маршрут версии 1.3 охватывает внутреннюю начальную ступень **A0/Pre-A1**, а также **A1** и **A2**. Уровни B1–C2 уже видны в карте курса как следующие этапы, но пока не запускаются.

> LernType не связан с Goethe-Institut, telc, TestDaF-Institut или BAMF. Внутренние экзамены проверяют только материал курса и не являются официальной CEFR-сертификацией или прогнозом результата внешнего экзамена.

## Что реализовано

- **Три самостоятельных курса:** A0/Pre-A1, A1 и A2 можно выбрать свободно; внутри каждого уроки открываются последовательно.
- **24 полноценных урока:** по восемь на уровень, 144 шага в едином ритме «теория → письмо → чтение → слушание и говорение → правило → контроль».
- **Внутренние экзамены:** 12 вопросов для A0, 16 для A1 и 20 для A2; экзамен появляется только внутри курса после восьми уроков.
- **Честная оценка речи:** запись обязательна как учебное свидетельство, но самооценка произношения не повышает машинно проверяемый балл урока или экзамена.
- **Строгий основной курс:** ответы курса проверяются локально по заданным эталонам, без сетевого ИИ и смыслового угадывания.
- **Отдельные интерактивные упражнения:** слова и предложения, набор текстов, двусторонний словарный тест, письмо, диктант и устная разминка не прерывают основной маршрут.
- **Честная проверка словарных разминок:** русские ответы принимают проверенные варианты и одну безопасную опечатку с показом нормативной формы; немецкие ответы остаются строгими.
- **Офлайн-словарь:** FreeDict/WikDict `rus-deu` и `deu-rus` версии 2025.11.23 в индексированной SQLite-базе.
- **Локальная аудиопрактика:** немецкий Windows TTS, запись и воспроизведение через микрофон; распознавания речи и автоматической оценки произношения нет.
- **Прогресс и повторение:** канонические события попыток, локальный прогресс курса и версионированное интервальное повторение `fsrs-like-v1`.
- **Интерфейс:** адаптивная тёплая glass-тема, полупрозрачные плитки, светлый/тёмный режим, Mica в Windows 11 и резервное оформление для Windows 10.

Курс A0–A2 распространяется одним локальным JSON-каталогом и не требует аккаунта, API-ключа или сети. Все объяснения, примеры, тексты, задания и экзамены написаны специально для LernType; внешние материалы использовались только для проверки последовательности, грамматических фактов и баланса навыков. Подробная методика и происхождение описаны в [документе о контенте курса](docs/COURSE-CONTENT.md).

Дополнительный каталог разминок по-прежнему содержит 150 слов, 70 двуязычных предложений и 35 текстов — по пять для каждого уровня Pre-A1–C2. Он не подменяет уроки курса и не запускается автоматически.

## Скачать и запустить

В GitHub Releases используются автономные архивы:

- `LernType-<version>-win-x64.zip` — обычные 64-битные ПК Windows;
- `LernType-<version>-win-arm64.zip` — устройства Windows on Arm.

1. Скачайте архив и одноимённый файл `.sha256`.
2. Сверьте SHA-256, распакуйте архив и запустите `LernType.exe`.
3. Для автопереключения ввода добавьте в Windows раскладки `ru-RU` и `de-DE`.

MSIX/App Installer подходит для пользовательской установки только тогда, когда конкретный релиз явно помечен как подписанный и цифровая подпись успешно проверяется. CI также создаёт короткоживущий **unsigned validation MSIX** для проверки структуры; он не является стабильным установщиком.

## Сборка из исходников

Требуются Windows 10/11 и **.NET 10 SDK**. Версия SDK закреплена в `global.json`, зависимости — в `packages.lock.json`. Скрипты упаковки запускаются в PowerShell 7 (`pwsh`).

```powershell
dotnet tool restore
dotnet restore LernType.sln --locked-mode
dotnet format LernType.sln --verify-no-changes --no-restore
dotnet build LernType.sln -c Release --no-restore -warnaserror
dotnet test LernType.sln -c Release --no-build --no-restore
dotnet run --project src/WortBruecke.App/WortBruecke.App.csproj
```

Автономная публикация обеих архитектур:

```powershell
dotnet restore src/WortBruecke.App/WortBruecke.App.csproj --locked-mode
dotnet publish src/WortBruecke.App/WortBruecke.App.csproj `
  -c Release -r win-x64 --self-contained true --no-restore `
  -o artifacts/publish/win-x64

dotnet publish src/WortBruecke.App/WortBruecke.App.csproj `
  -c Release -r win-arm64 --self-contained true --no-restore `
  -o artifacts/publish/win-arm64
```

Верификация MSIX-манифеста без публикации неподписанного пакета:

```powershell
./tools/Build-Msix.ps1 `
  -PublishDirectory artifacts/publish/win-x64 `
  -Architecture x64 -AllowUnsigned
```

Подписанный MSIX требует PFX с закрытым ключом и `Publisher`, точно совпадающий с subject сертификата:

```powershell
$password = Read-Host 'PFX password' -AsSecureString
./tools/Build-Msix.ps1 `
  -PublishDirectory artifacts/publish/win-x64 `
  -Architecture x64 `
  -CertificatePath C:\secure\LernType-signing.pfx `
  -CertificatePassword $password `
  -TimestampUri 'https://timestamp.example.org'
```

App Installer создаётся только для уже подписанного и размещённого по HTTPS MSIX. Полная процедура — в [docs/RELEASING.md](docs/RELEASING.md).

## Локальные данные и безопасное обновление

Профиль распакованной версии находится в `%LOCALAPPDATA%\LernType`:

- `lerntype.db` — контент, канонические попытки, состояния повторения, прогресс курса и данные предыдущих версий;
- `settings.json` — локальные настройки и защищённый для текущего пользователя API-ключ;
- `Backups` и `migration-journal.jsonl` — управляемые копии и журнал восстановления.

При обнаружении старого `%LOCALAPPDATA%\WortBruecke` мигратор учитывает SQLite WAL, выполняет checkpoint/SQLite Backup API, `quick_check` и сверку инвентаря, затем атомарно продвигает проверенную копию. Исходник и предмиграционная копия сохраняются, а журнал позволяет повторить или откатить прерванный перенос. Два непустых профиля не объединяются молча.

В версии 1.3 незавершённая «Моя библиотека» удалена из публичной навигации и больше не создаёт новые проекты. Существующие записи предыдущих версий сохраняются миграцией без потери данных и остаются доступными для проверенного отката. Временные аудиозаписи не сохраняются по умолчанию.

## Контент и словарь

- каталог: `src/WortBruecke.App/Content/catalog.json`;
- основной курс A0–A2: `src/WortBruecke.App/Content/courses-a0-a2.json`;
- происхождение основного курса: `src/WortBruecke.App/Content/course-provenance.json`;
- происхождение и лицензии текстов: `src/WortBruecke.App/Content/passage-provenance.json`;
- экзаменационные схемы: `src/WortBruecke.App/Content/exams.json`;
- словарь и лицензии: `src/WortBruecke.App/Assets/Dictionary/FreeDict`.

Уровни встроенных текстов являются редакционной оценкой для последовательности практики, а не официальной CEFR-сертификацией. Все 35 записей имеют происхождение, лицензию MIT и честный статус `pending-independent-review`; литературные мотивы используются только в новых пересказах произведений общественного достояния.

Конвертер FreeDict TEI P5:

```powershell
dotnet run --project tools/WortBruecke.DictionaryBuilder -- `
  output.sqlite rus-deu.tei deu-rus.tei
```

Формат подписанных офлайн-контент-пакетов проверяет RSA-PSS подпись манифеста, SHA-256 каждого файла, совместимость приложения, лимиты размера и защиту от path traversal. Публикационный процесс и требования к рецензированию описаны в [docs/CONTENT-GOVERNANCE.md](docs/CONTENT-GOVERNANCE.md).

## Архитектура и проверка качества

- `WortBruecke.Core` — учебные модели, канонические события попыток, оценивание, освоение и интервальное повторение;
- `WortBruecke.Infrastructure` — SQLite, WAL-aware миграция, офлайн-словарь, аудио, защищённые настройки и сетевой клиент;
- `WortBruecke.App` — WPF/MVVM, DI/Generic Host, навигация, темы и учебные сценарии;
- `WortBruecke.Tests` — unit-, integration-, persistence-, resilience-, privacy- и content-тесты.

CI выполняет locked restore, форматирование, Debug/Release build с warnings-as-errors, тесты и порог покрытия, транзитивный vulnerability audit, CycloneDX SBOM, CodeQL и self-contained publish для x64/arm64. Все сторонние Actions закреплены полными commit SHA.

## Проверка конкретного релиза

Каждый GitHub Release сопровождается файлом `LernType-<version>-verification.md`, SBOM и
`SHA256SUMS`. В записи указываются точный commit, буквальные команды и коды выхода, число тестов,
покрытие, результат аудита зависимостей, хэши обеих архитектур, миграционный inventory, UI-smoke и
проверенный rollback. Это исключает смешивание результатов разных исходных состояний.

Локальная runtime-матрица выполняется на Windows 11 x64 при `1180×760`, `820×600` и `720×520`;
успех требует ожидаемый UI Automation landmark, отсутствие shell error/технического кода и штатное
закрытие с exit `0`. Arm64 cross-publish дополнительно проверяется по PE machine `0xAA64`, но его
native runtime-статус всегда указывается отдельно в verification record.

Полная воспроизводимая процедура находится в [регламенте выпуска](docs/RELEASING.md).

## Границы текущей версии

- Основной последовательный курс полностью опубликован только для A0/Pre-A1–A2; B1–C2 пока показаны как планируемые и не маскируются упражнениями другого уровня.
- Локальная устная практика записывает и воспроизводит речь, но не выполняет фонетическое распознавание; результат такой попытки помечается как самооценка.
- Внутренние экзамены открываются только после уроков выбранного курса и не воспроизводят официальные форматы Goethe/telc/TestDaF.
- Личная библиотека и отдельный экзаменационный центр скрыты из пользовательского интерфейса до профессиональной переработки.
- Windows 11 является основной целью; Windows 10 22H2 поддерживается для ZIP-сборки в режиме best effort и не считается runtime-проверенной без отдельной записи на реальной системе.
