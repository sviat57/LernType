# 1. Product purpose

LernType guides Russian-speaking Windows users from a true beginner foundation (A0) through CEFR C2 and prepares every language skill for recognized German examinations, while keeping focused offline practice and automatic keyboard-layout switching.

# 2. Primary user

A Russian-speaking learner of German at any stage from first contact through C2 who wants a visible route, varied daily practice and evidence-based exam readiness on a Windows 10/11 desktop or laptop.

# 3. Principles

1. The keyboard disappears from the learner’s mental load — language transitions are explicit in the exercise and automatic in Windows.
2. The route is explicit — every level shows objectives, available practice, mastery evidence and the next recommended action.
3. All language skills matter — vocabulary and grammar support reading, listening, writing, speaking and mediation rather than replacing them.
4. Correction teaches more than judgement — every wrong answer explains the target and schedules a useful next attempt.
5. Offline remains useful — the core curriculum, progress and practice work without an account or network; optional services are clearly marked.
6. Exam readiness is evidence, not a badge — simulations follow versioned official blueprints and report readiness per section.
7. Honest capability beats invisible failure — missing content, layouts, API configuration and platform limits are explained in place.

# 4. Success metric for the surface

A learner can always identify their current level, weakest skill and next activity; complete a balanced week of practice; and run a timed simulation whose section coverage and scoring rules can be traced to a versioned exam blueprint.

# 5. Out of scope

- Does not provide languages other than Russian and German in v1.
- Does not claim that an internal readiness score guarantees an external exam result.
- Does not implement accounts, cloud synchronisation, streaks or XP.
- Does not promise universal keyboard-layout switching behaviour beyond the tested Windows configuration.
- Does not require an LLM key for offline practice.
